# SQLAlchemy driver for ``postgresql://`` / ``postgresql+psycopg2://``
# URLs and is what ``DATABASE_URL`` in the bundled Helm chart resolves
# to. ``psycopg[binary]`` (psycopg 3) is installed alongside it for

# on slim container images where libpq headers are absent. The source
# build fallback for ``psycopg2-binary`` is enabled in the Dockerfile

# wheel for the newest CPython.
